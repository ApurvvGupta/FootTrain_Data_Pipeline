FootTrain - IMU-Based Data Analytics and Processing Pipeline
May 2026 to Jul 2026

Project Overview

This repository contains an end-to-end Python data analytics pipeline designed for large-scale IMU motion capture datasets. The system automates several crucial stages of data handling, including data ingestion, preprocessing, feature engineering, exploratory data analysis, gait event detection, and visualization. The primary libraries utilized for these processes include Pandas, NumPy, SciPy, and Matplotlib.

Key Capabilities

The pipeline facilitates comprehensive data analysis and statistical evaluation on multi-participant experimental datasets. This is achieved by extracting key features, identifying underlying trends and insights, and validating overall data quality.

Additionally, the codebase supports conducting rigorous hypothesis testing and generating automated reports alongside publication-ready visualizations. These outputs are essential for supporting informed, data-driven decision making.

Structure and Usage

The provided scripts cover different phases of gait event detection and normalized plotting. Make sure to provide the necessary input datasets before executing the main scripts. The code is modularly organized to handle different limbs and peak detection phases independently.
